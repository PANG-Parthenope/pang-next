# PANG Footer Minimal 0.1.0

Minimal custom footer for the PANG website.

## Visual structure
Left:
- PANG
- PArthenope Navigation Group
- University of Naples Parthenope

Right:
- CONTACT
- group email
- LinkedIn

Bottom:
- dynamic copyright year

## Settings
After activation:

Appearance > PANG Footer

Set:
- Group email
- LinkedIn URL
- Institution

Email and LinkedIn are hidden automatically if left blank.
