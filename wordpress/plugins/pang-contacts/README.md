# PANG Contacts 0.1.0

Creates a Contacts page at `/contacts/` and inserts `[pang_contacts]`.

## Content
- University of Naples Parthenope
- Centro Direzionale Isola C4
- 80143 Naples, Italy
- pang@uniparthenope.it
- +395476610
- Collaborate with Us
- Stay Tuned / Latest News
- Stylized map highlighting Naples

The Website row is intentionally omitted.

## Installation
Upload and activate the ZIP from WordPress > Plugins > Add New > Upload Plugin.

On activation, the plugin creates the Contacts page if it does not already exist.
If a Contacts page already exists, its content is replaced with `[pang_contacts]`.
